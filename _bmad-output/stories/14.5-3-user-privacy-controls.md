# Story 14.5-3: User Privacy Controls

Status: Ready for Dev
Priority: P0

## Story

**As a** Contextor user,
**I want** granular control over my data,
**So that** I can manage what is captured, how long it is kept, and delete it when needed.

## Acceptance Criteria

1. **Given** I am on the Privacy Settings page
   **When** I view my controls
   **Then** I see options for:
   - Excluded projects list
   - Custom redaction patterns
   - Capture pause toggle

   > **Note:** Data retention period configuration is handled in Story 14.5-6 (Privacy Preferences Database).

2. **Given** I add a project to the excluded list
   **When** I work in that project
   **Then** no prompts are captured from that project
   **And** existing prompts from that project remain unchanged (not retroactively deleted)

3. **Given** I add a custom redaction pattern
   **When** the pattern is a valid regex
   **Then** it is saved and applied to future captures
   **And** I see a confirmation of the pattern

4. **Given** I add an invalid regex pattern
   **When** I try to save
   **Then** I see an error message explaining the issue
   **And** the pattern is not saved

5. **Given** I click "Delete All My Data"
   **When** I confirm the action
   **Then** my data is soft-deleted (marked with `deleted_at` timestamp)
   **And** I see a confirmation message with 7-day recovery notice
   **And** data is permanently deleted after 7-day grace period

6. **Given** I deleted my data within the last 7 days
   **When** I click "Recover My Data"
   **Then** my soft-deleted data is restored
   **And** I see a confirmation message

7. **Given** I click "Export My Data"
   **When** the export completes
   **Then** I receive a JSON file with all my data

8. **Given** I have a large amount of data to export (>10MB)
   **When** I click "Export My Data"
   **Then** I see a progress indicator
   **And** export is chunked to prevent timeout

9. **Given** I toggle "Pause Capture"
   **When** capture is paused
   **Then** no new prompts are captured until I resume
   **And** I see a visual indicator that capture is paused

## Dev Notes

### CLI Integration (Privacy-First Approach)

The CLI capture hook must respect user privacy preferences. **Recommended: Option C - Local Config File** for privacy-first design (no network call needed).

**How it works:**
1. Web UI saves preferences to both database AND generates a local config file
2. When user updates preferences in UI, sync to local project via CLI command
3. Capture hook reads local config file before each capture (no network call)
4. If config missing, default to capture enabled (first-time users)

**Local config location:** `.contextor/privacy.json` in project root

```json
{
  "capture_paused": false,
  "excluded_projects": ["/path/to/secret-project", "internal-*"],
  "custom_patterns": ["COMPANY-\\d+", "SSN-\\d{3}-\\d{2}-\\d{4}"]
}
```

**Sync command:** `npx @contextor/cli sync-privacy`
- Fetches preferences from API and writes to local config
- Run after changing preferences in web UI
- Or configure as post-save webhook

**Capture hook pseudocode:**
```bash
# Load local privacy config
PRIVACY_CONFIG="$CLAUDE_PROJECT_DIR/.contextor/privacy.json"

if [ -f "$PRIVACY_CONFIG" ]; then
  CAPTURE_PAUSED=$(jq -r '.capture_paused' "$PRIVACY_CONFIG")
  if [ "$CAPTURE_PAUSED" = "true" ]; then
    exit 0  # Skip capture silently
  fi

  # Check if current project is excluded
  PROJECT_PATH=$(pwd)
  EXCLUDED=$(jq -r --arg p "$PROJECT_PATH" '.excluded_projects | map(select(. == $p or ($p | test(.))))' "$PRIVACY_CONFIG")
  if [ "$EXCLUDED" != "[]" ]; then
    exit 0  # Skip capture silently
  fi
fi

# Proceed with capture...
```

### Rate Limiting

Per security architecture, privacy endpoints are rate limited:

| Endpoint | Limit | Window |
|----------|-------|--------|
| `POST /api/privacy/delete-all` | 3 requests | per day |
| `POST /api/privacy/recover` | 3 requests | per day |
| `GET /api/privacy/export` | 1 request | per hour |

Use existing `lib/rate-limit` infrastructure with `privacyRateLimit` configuration.

### Soft Delete with Recovery

Data deletion uses soft-delete pattern for user safety:

```sql
-- Add soft delete column
ALTER TABLE prompts ADD COLUMN deleted_at TIMESTAMPTZ;
ALTER TABLE prompt_analysis ADD COLUMN deleted_at TIMESTAMPTZ;

-- Create index for efficient queries
CREATE INDEX idx_prompts_deleted_at ON prompts(deleted_at) WHERE deleted_at IS NOT NULL;

-- Scheduled job to permanently delete after 7 days
CREATE OR REPLACE FUNCTION permanent_delete_expired()
RETURNS void AS $$
BEGIN
  DELETE FROM prompts
  WHERE deleted_at IS NOT NULL
  AND deleted_at < NOW() - INTERVAL '7 days';

  DELETE FROM prompt_analysis
  WHERE deleted_at IS NOT NULL
  AND deleted_at < NOW() - INTERVAL '7 days';
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;
```

### Excluded Projects Component

```tsx
// components/privacy/excluded-projects.tsx
'use client';

import { useState } from 'react';
import { Button } from '@/components/ui/button';
import { Input } from '@/components/ui/input';
import { Badge } from '@/components/ui/badge';
import { X, Plus } from 'lucide-react';
import { usePrivacyPreferences } from '@/lib/hooks/use-privacy-preferences';

export function ExcludedProjects() {
  const { preferences, updatePreferences } = usePrivacyPreferences();
  const [newProject, setNewProject] = useState('');

  const addProject = () => {
    if (!newProject.trim()) return;
    const updated = [...(preferences.excludedProjects || []), newProject.trim()];
    updatePreferences({ excludedProjects: updated });
    setNewProject('');
  };

  const removeProject = (project: string) => {
    const updated = preferences.excludedProjects?.filter(p => p !== project) || [];
    updatePreferences({ excludedProjects: updated });
  };

  return (
    <div className="space-y-4">
      <div className="flex gap-2">
        <Input
          placeholder="Project path or name"
          value={newProject}
          onChange={(e) => setNewProject(e.target.value)}
          onKeyDown={(e) => e.key === 'Enter' && addProject()}
        />
        <Button onClick={addProject}>
          <Plus className="h-4 w-4" />
        </Button>
      </div>

      <div className="flex flex-wrap gap-2">
        {preferences.excludedProjects?.map((project) => (
          <Badge key={project} variant="secondary" className="pr-1">
            {project}
            <button
              onClick={() => removeProject(project)}
              className="ml-1 hover:text-destructive"
            >
              <X className="h-3 w-3" />
            </button>
          </Badge>
        ))}
      </div>
    </div>
  );
}
```

### Custom Patterns Component

```tsx
// components/privacy/custom-patterns.tsx
'use client';

import { useState } from 'react';
import { Button } from '@/components/ui/button';
import { Input } from '@/components/ui/input';
import { Alert, AlertDescription } from '@/components/ui/alert';
import { X, Plus, AlertCircle, Check } from 'lucide-react';

export function CustomPatterns() {
  const { preferences, updatePreferences } = usePrivacyPreferences();
  const [newPattern, setNewPattern] = useState('');
  const [testText, setTestText] = useState('');
  const [error, setError] = useState('');
  const [testResult, setTestResult] = useState<boolean | null>(null);

  const validatePattern = (pattern: string): boolean => {
    try {
      new RegExp(pattern);
      return true;
    } catch {
      return false;
    }
  };

  const addPattern = () => {
    if (!newPattern.trim()) return;

    if (!validatePattern(newPattern)) {
      setError('Invalid regex pattern');
      return;
    }

    const updated = [...(preferences.customPatterns || []), newPattern.trim()];
    updatePreferences({ customPatterns: updated });
    setNewPattern('');
    setError('');
  };

  const testPattern = () => {
    if (!newPattern || !testText) return;
    try {
      const regex = new RegExp(newPattern, 'g');
      setTestResult(regex.test(testText));
      setError('');
    } catch {
      setError('Invalid regex pattern');
      setTestResult(null);
    }
  };

  return (
    <div className="space-y-4">
      {/* Pattern input */}
      <div className="flex gap-2">
        <Input
          placeholder="Regex pattern (e.g., COMPANY-\\d+)"
          value={newPattern}
          onChange={(e) => {
            setNewPattern(e.target.value);
            setError('');
            setTestResult(null);
          }}
        />
        <Button onClick={addPattern}>
          <Plus className="h-4 w-4" />
        </Button>
      </div>

      {/* Test input */}
      <div className="flex gap-2">
        <Input
          placeholder="Test your pattern against this text"
          value={testText}
          onChange={(e) => setTestText(e.target.value)}
        />
        <Button variant="outline" onClick={testPattern}>
          Test
        </Button>
      </div>

      {/* Validation feedback */}
      {error && (
        <Alert variant="destructive">
          <AlertCircle className="h-4 w-4" />
          <AlertDescription>{error}</AlertDescription>
        </Alert>
      )}

      {testResult !== null && (
        <Alert variant={testResult ? 'default' : 'destructive'}>
          {testResult ? <Check className="h-4 w-4" /> : <X className="h-4 w-4" />}
          <AlertDescription>
            {testResult ? 'Pattern matches!' : 'Pattern does not match'}
          </AlertDescription>
        </Alert>
      )}

      {/* Existing patterns */}
      <div className="space-y-2">
        {preferences.customPatterns?.map((pattern, i) => (
          <div key={i} className="flex items-center gap-2 p-2 bg-muted rounded">
            <code className="flex-1 text-sm">{pattern}</code>
            <Button
              variant="ghost"
              size="sm"
              onClick={() => {
                const updated = preferences.customPatterns?.filter((_, idx) => idx !== i);
                updatePreferences({ customPatterns: updated });
              }}
            >
              <X className="h-4 w-4" />
            </Button>
          </div>
        ))}
      </div>
    </div>
  );
}
```

### Data Actions Component

```tsx
// components/privacy/data-actions.tsx
'use client';

import { useState } from 'react';
import { Button } from '@/components/ui/button';
import { Progress } from '@/components/ui/progress';
import {
  AlertDialog,
  AlertDialogAction,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogTitle,
} from '@/components/ui/alert-dialog';
import { Download, Trash2, Loader2, RotateCcw } from 'lucide-react';
import { toast } from 'sonner';
import { usePrivacyPreferences } from '@/lib/hooks/use-privacy-preferences';

export function DataActions() {
  const { hasPendingDeletion, deletionExpiresAt } = usePrivacyPreferences();
  const [showDeleteDialog, setShowDeleteDialog] = useState(false);
  const [isDeleting, setIsDeleting] = useState(false);
  const [isRecovering, setIsRecovering] = useState(false);
  const [isExporting, setIsExporting] = useState(false);
  const [exportProgress, setExportProgress] = useState(0);

  const handleExport = async () => {
    setIsExporting(true);
    setExportProgress(0);
    try {
      // For large exports, use streaming with progress
      const response = await fetch('/api/privacy/export');

      if (!response.ok) {
        if (response.status === 429) {
          toast.error('Export limit reached. Try again in 1 hour.');
          return;
        }
        throw new Error('Export failed');
      }

      // Check if chunked response (large export)
      const contentLength = response.headers.get('content-length');
      if (contentLength && parseInt(contentLength) > 10 * 1024 * 1024) {
        // Stream large response with progress
        const reader = response.body?.getReader();
        const chunks: Uint8Array[] = [];
        let receivedLength = 0;
        const totalLength = parseInt(contentLength);

        while (reader) {
          const { done, value } = await reader.read();
          if (done) break;
          chunks.push(value);
          receivedLength += value.length;
          setExportProgress((receivedLength / totalLength) * 100);
        }

        const blob = new Blob(chunks, { type: 'application/json' });
        downloadBlob(blob);
      } else {
        const blob = await response.blob();
        downloadBlob(blob);
      }

      toast.success('Data exported successfully');
    } catch {
      toast.error('Failed to export data');
    } finally {
      setIsExporting(false);
      setExportProgress(0);
    }
  };

  const downloadBlob = (blob: Blob) => {
    const url = window.URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = `contextor-data-${new Date().toISOString().split('T')[0]}.json`;
    a.click();
    window.URL.revokeObjectURL(url);
  };

  const handleDelete = async () => {
    setIsDeleting(true);
    try {
      const response = await fetch('/api/privacy/delete-all', { method: 'POST' });
      if (!response.ok) {
        if (response.status === 429) {
          toast.error('Delete limit reached. Try again tomorrow.');
          return;
        }
        throw new Error('Delete failed');
      }
      toast.success('Data scheduled for deletion. You have 7 days to recover it.');
      setShowDeleteDialog(false);
    } catch {
      toast.error('Failed to delete data');
    } finally {
      setIsDeleting(false);
    }
  };

  const handleRecover = async () => {
    setIsRecovering(true);
    try {
      const response = await fetch('/api/privacy/recover', { method: 'POST' });
      if (!response.ok) throw new Error('Recovery failed');
      toast.success('Data recovered successfully');
    } catch {
      toast.error('Failed to recover data');
    } finally {
      setIsRecovering(false);
    }
  };

  return (
    <div className="space-y-4">
      {/* Recovery banner if deletion pending */}
      {hasPendingDeletion && (
        <div className="p-4 bg-yellow-50 dark:bg-yellow-900/20 border border-yellow-200 dark:border-yellow-800 rounded-lg">
          <div className="flex items-center justify-between">
            <div>
              <p className="font-medium text-yellow-800 dark:text-yellow-200">
                Data deletion scheduled
              </p>
              <p className="text-sm text-yellow-600 dark:text-yellow-400">
                Your data will be permanently deleted on{' '}
                {new Date(deletionExpiresAt).toLocaleDateString()}.
              </p>
            </div>
            <Button variant="outline" onClick={handleRecover} disabled={isRecovering}>
              {isRecovering ? (
                <Loader2 className="h-4 w-4 animate-spin" />
              ) : (
                <RotateCcw className="h-4 w-4 mr-2" />
              )}
              Recover My Data
            </Button>
          </div>
        </div>
      )}

      <div className="flex gap-4">
        <Button variant="outline" onClick={handleExport} disabled={isExporting}>
          {isExporting ? (
            <Loader2 className="h-4 w-4 animate-spin mr-2" />
          ) : (
            <Download className="h-4 w-4 mr-2" />
          )}
          Export My Data
        </Button>

        <Button
          variant="destructive"
          onClick={() => setShowDeleteDialog(true)}
          disabled={hasPendingDeletion}
        >
          <Trash2 className="h-4 w-4 mr-2" />
          Delete All My Data
        </Button>
      </div>

      {/* Export progress for large exports */}
      {isExporting && exportProgress > 0 && (
        <div className="space-y-2">
          <Progress value={exportProgress} />
          <p className="text-sm text-muted-foreground">
            Exporting... {Math.round(exportProgress)}%
          </p>
        </div>
      )}

      <AlertDialog open={showDeleteDialog} onOpenChange={setShowDeleteDialog}>
        <AlertDialogContent>
          <AlertDialogHeader>
            <AlertDialogTitle>Delete All Data?</AlertDialogTitle>
            <AlertDialogDescription className="space-y-2">
              <p>
                This will schedule deletion of all your captured prompts, analysis
                results, and session data.
              </p>
              <p className="font-medium">
                You will have 7 days to recover your data before it is permanently deleted.
              </p>
            </AlertDialogDescription>
          </AlertDialogHeader>
          <AlertDialogFooter>
            <AlertDialogCancel>Cancel</AlertDialogCancel>
            <AlertDialogAction
              onClick={handleDelete}
              className="bg-destructive text-destructive-foreground"
            >
              {isDeleting ? (
                <Loader2 className="h-4 w-4 animate-spin" />
              ) : (
                'Delete Everything'
              )}
            </AlertDialogAction>
          </AlertDialogFooter>
        </AlertDialogContent>
      </AlertDialog>
    </div>
  );
}
```

### API Endpoints

```typescript
// app/api/privacy/export/route.ts
import { privacyRateLimit } from '@/lib/rate-limit';

export async function GET(request: Request) {
  const supabase = await createServerClient();
  const { data: { user } } = await supabase.auth.getUser();

  if (!user) {
    return new Response('Unauthorized', { status: 401 });
  }

  // Rate limit: 1 export per hour
  const { success } = await privacyRateLimit.export.limit(user.id);
  if (!success) {
    return new Response('Rate limit exceeded', { status: 429 });
  }

  // Gather all user data (exclude soft-deleted)
  const [prompts, preferences] = await Promise.all([
    supabase.from('prompts').select('*').eq('user_id', user.id).is('deleted_at', null),
    supabase.from('privacy_preferences').select('*').eq('user_id', user.id).single(),
  ]);

  const exportData = {
    exportedAt: new Date().toISOString(),
    user: { id: user.id, email: user.email },
    prompts: prompts.data,
    preferences: preferences.data,
  };

  return new Response(JSON.stringify(exportData, null, 2), {
    headers: {
      'Content-Type': 'application/json',
      'Content-Disposition': `attachment; filename="contextor-export.json"`,
    },
  });
}
```

```typescript
// app/api/privacy/delete-all/route.ts
import { privacyRateLimit } from '@/lib/rate-limit';

export async function POST(request: Request) {
  const supabase = await createServerClient();
  const { data: { user } } = await supabase.auth.getUser();

  if (!user) {
    return new Response('Unauthorized', { status: 401 });
  }

  // Rate limit: 3 deletes per day
  const { success } = await privacyRateLimit.delete.limit(user.id);
  if (!success) {
    return new Response('Rate limit exceeded', { status: 429 });
  }

  const now = new Date().toISOString();

  // Soft delete all user data
  await Promise.all([
    supabase.from('prompts').update({ deleted_at: now }).eq('user_id', user.id).is('deleted_at', null),
    supabase.from('prompt_analysis').update({ deleted_at: now }).eq('user_id', user.id).is('deleted_at', null),
  ]);

  return Response.json({
    message: 'Data scheduled for deletion',
    expiresAt: new Date(Date.now() + 7 * 24 * 60 * 60 * 1000).toISOString(),
  });
}
```

```typescript
// app/api/privacy/recover/route.ts
import { privacyRateLimit } from '@/lib/rate-limit';

export async function POST(request: Request) {
  const supabase = await createServerClient();
  const { data: { user } } = await supabase.auth.getUser();

  if (!user) {
    return new Response('Unauthorized', { status: 401 });
  }

  // Rate limit: 3 recoveries per day
  const { success } = await privacyRateLimit.delete.limit(user.id);
  if (!success) {
    return new Response('Rate limit exceeded', { status: 429 });
  }

  // Recover all soft-deleted data within 7-day window
  const sevenDaysAgo = new Date(Date.now() - 7 * 24 * 60 * 60 * 1000).toISOString();

  await Promise.all([
    supabase.from('prompts').update({ deleted_at: null }).eq('user_id', user.id).gte('deleted_at', sevenDaysAgo),
    supabase.from('prompt_analysis').update({ deleted_at: null }).eq('user_id', user.id).gte('deleted_at', sevenDaysAgo),
  ]);

  return Response.json({ message: 'Data recovered successfully' });
}
```
