# Product-Led Growth (PLG) Marketing Playbook

> Maven's guide to marketing strategies for product-led growth companies.

---

## What is PLG?

**Product-Led Growth** is a go-to-market strategy where the product itself is the primary driver of customer acquisition, conversion, and expansion.

### PLG vs Traditional SaaS

| Aspect | Traditional (Sales-Led) | Product-Led |
|--------|------------------------|-------------|
| **First Touch** | Sales demo | Self-service signup |
| **Conversion** | Sales closes | Product converts |
| **Expansion** | Account manager | Usage-based upsell |
| **Time to Value** | Weeks/months | Minutes/hours |
| **CAC** | Higher | Lower |
| **Scale** | Linear (sales headcount) | Exponential (product) |

### Famous PLG Examples
- Slack, Zoom, Notion
- Figma, Canva, Loom
- Calendly, Dropbox, Airtable
- Atlassian, Stripe, Twilio

## PLG Marketing Strategies

### 1. Top-of-Funnel: Drive Free Signups

**Content Marketing (SEO)**
- Target problem-aware searches
- Create comparison content ("X vs Y")
- Build template/resource libraries
- Document integrations and use cases

**Example Topics:**
- "How to [solve problem]"
- "Best [category] tools in [year]"
- "[Your product] vs [competitor]"
- "Free [resource] template"

**Social Proof at Scale:**
- "Join 100,000+ teams using [Product]"
- User-generated content programs
- Public customer logos
- G2/Capterra review campaigns

**Community-Led Growth:**
- Build community around use case
- User forums and help communities
- Slack/Discord communities
- User-generated templates/resources

### 2. Activation: Drive to "Aha" Moment

**Define Your "Aha" Moment:**
- What action correlates with retention?
- When do users "get it"?
- What's the shortest path to value?

**Examples:**
| Product | "Aha" Moment |
|---------|--------------|
| Slack | Sending 2000 messages as a team |
| Dropbox | Putting first file in folder |
| Zoom | Completing first video call |
| Notion | Creating first page with content |

**Marketing's Role in Activation:**
- Onboarding email sequences
- In-app messaging and guides
- Educational content (videos, docs)
- Segmented nurture by use case

**Activation Email Sequence:**
```
Email 1 (Day 0): Welcome + Quick Start
Email 2 (Day 1): Complete [Key Action]
Email 3 (Day 3): Feature highlight
Email 4 (Day 5): Social proof / case study
Email 5 (Day 7): Need help? (Support offer)
Email 6 (Day 10): Advanced feature
Email 7 (Day 14): Trial ending (if applicable)
```

### 3. Engagement: Build Habits

**Usage-Based Triggers:**
- "You've created X - try this next"
- "Your team is active - invite more"
- "You haven't logged in - here's what's new"
- "You hit a limit - upgrade to continue"

**Re-engagement Campaigns:**
- Inactive user sequences
- Feature announcement emails
- "What's new" digests
- Win-back campaigns

**Content for Engagement:**
- Use case tutorials
- Advanced feature guides
- Best practices content
- Community showcases

### 4. Monetization: Convert Free to Paid

**Freemium Triggers:**
- Feature gating (premium features)
- Usage limits (storage, users, actions)
- Support tiers (priority support)
- Integration limits

**Conversion Triggers:**
- Approaching usage limits
- Team size growth
- Feature discovery
- Time-based (trial expiring)

**Upgrade Marketing:**
- In-app upgrade prompts
- Email sequences on triggers
- Comparison pages (free vs paid)
- Case studies showing paid ROI

**Pricing Page Optimization:**
- Clear tier differentiation
- Feature comparison tables
- Social proof near CTAs
- FAQ addressing objections

### 5. Expansion: Upsell and Viral

**Viral Loops:**

| Loop Type | Example |
|-----------|---------|
| **Invite-based** | "Invite colleagues to collaborate" |
| **Embed/Share** | Public links, embedded content |
| **Network Effect** | More users = more value |
| **Word of Mouth** | NPS program, referrals |

**Expansion Revenue:**
- Seat-based growth (more users)
- Usage-based growth (more usage)
- Tier-based growth (upgrade plans)
- Add-on purchases

**Referral Programs:**
- Two-sided rewards (referrer + referee)
- Easy sharing mechanics
- Track and optimize viral coefficient
- Segment high-referrers for programs

## PLG Metrics

### Key Metrics to Track

**Acquisition:**
| Metric | What It Measures |
|--------|------------------|
| Signups | Top of funnel volume |
| Signup Rate | Landing page effectiveness |
| CAC | Cost per acquired user |
| Viral Coefficient | Users brought by users |

**Activation:**
| Metric | What It Measures |
|--------|------------------|
| Time to Value (TTV) | Speed to "aha" moment |
| Activation Rate | % reaching "aha" moment |
| Day 1/7/30 Retention | Early engagement |

**Monetization:**
| Metric | What It Measures |
|--------|------------------|
| Free to Paid Rate | Conversion efficiency |
| Time to Convert | Sales cycle length |
| ARPU | Revenue per user |
| PQL to Customer | Product-qualified conversion |

**Expansion:**
| Metric | What It Measures |
|--------|------------------|
| Net Revenue Retention | Expansion minus churn |
| Expansion MRR | Upsell revenue |
| Viral Coefficient | K-factor |
| NPS | Likelihood to recommend |

### Benchmarks

| Metric | Average | Good | Great |
|--------|---------|------|-------|
| Free to Paid | 2-5% | 5-10% | >10% |
| Activation Rate | 20-40% | 40-60% | >60% |
| Day 1 Retention | 20-30% | 30-50% | >50% |
| Viral Coefficient | 0.1-0.3 | 0.3-0.7 | >0.7 |
| NRR | 90-100% | 100-120% | >120% |

## PLG Growth Loops

### Types of Growth Loops

**1. User-Generated Content Loop**
```
User creates content → Content is shareable →
New users discover → New users sign up →
New users create content → ...
```
*Example: Canva designs, Notion templates*

**2. Collaborative Loop**
```
User invites team → Team uses product →
More value from collaboration →
Team invites more people → ...
```
*Example: Slack, Figma, Notion*

**3. Embed/Share Loop**
```
User creates shareable asset → Asset embedded/shared →
Viewers see "Made with [Product]" →
Viewers sign up → ...
```
*Example: Loom videos, Typeform forms*

**4. API/Integration Loop**
```
Developer builds integration → Users use integration →
More users attracted to ecosystem →
More developers build → ...
```
*Example: Stripe, Twilio, Zapier*

### Designing Your Growth Loop

**Questions to Ask:**
1. What do users create that's shareable?
2. How do users naturally invite others?
3. Where does your product appear to non-users?
4. What triggers word-of-mouth?
5. How can you make sharing rewarding?

## Common PLG Marketing Mistakes

1. **Treating free users like paid users**
   - Different messaging and value props needed

2. **Ignoring activation**
   - Signups without activation waste CAC

3. **No product-marketing alignment**
   - In-app and email must coordinate

4. **Generic onboarding**
   - Segment by use case and persona

5. **Premature monetization pressure**
   - Value first, revenue follows

6. **No viral mechanics**
   - Missing built-in growth loops

7. **Over-relying on one channel**
   - PLG needs diversified acquisition

8. **Ignoring power users**
   - Champions drive word of mouth

9. **No PQL definition**
   - Need to know who's ready for upgrade

10. **Siloed teams**
    - PLG requires product + marketing + sales alignment

## PLG Marketing Playbook: First 90 Days

### Days 1-30: Foundation
- [ ] Define "aha" moment and activation metrics
- [ ] Map customer journey (signup to paid)
- [ ] Set up analytics and tracking
- [ ] Create onboarding email sequence
- [ ] Audit current signup flow

### Days 31-60: Optimization
- [ ] Implement lifecycle messaging
- [ ] Launch first SEO content
- [ ] Set up PQL definition and routing
- [ ] A/B test signup flow
- [ ] Build first viral/share mechanic

### Days 61-90: Scale
- [ ] Launch paid acquisition (if ready)
- [ ] Build referral program
- [ ] Create template/resource library
- [ ] Implement expansion triggers
- [ ] Document and share learnings
