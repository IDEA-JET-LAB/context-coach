Design Notes

Key Design Decisions:

  • Dark mode as default - reduces eye strain for developers
  • Vibrant card colors inspired by Sparks Dashboard - instant visual scanning
  • No red for low scores - coral ("growth") feels encouraging, not punishing
  • Icon-only sidebar (64px) - Linear-inspired minimal chrome
  • Large border radius (16px) on cards - modern, approachable feel
  • Bold metric typography - scores are the hero element
