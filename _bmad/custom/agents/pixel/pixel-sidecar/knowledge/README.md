# Pixel Knowledge Base

This directory contains reference materials and domain knowledge for image generation.

## Contents

Add any of the following to help Pixel generate better images:

### Brand Guidelines
- `brand-guide.md` - Company brand guidelines
- `color-palette.md` - Official color specifications
- `typography.md` - Font usage guidelines

### Style References
- `style-examples/` - Example images showing desired aesthetic
- `mood-board.md` - Mood board description
- `do-and-dont.md` - Visual do's and don'ts

### Technical Specs
- `image-specs.md` - Required image specifications for different uses
- `platform-requirements.md` - Platform-specific image requirements

## Usage

Files placed here will be referenced by Pixel when generating images.
Use markdown format for text files.
Images can be used as style references.
